# Matemáticas Aplicadas

Este repositorio contiene actividades, ejercicios y proyectos relacionados con Matemáticas Aplicadas, desarrollados principalmente en Python y Jupyter Notebook.

Aquí se documentan y organizan tareas de análisis matemático, modelado funcional, resolución de problemas y visualización gráfica usando herramientas como NumPy, SciPy y Matplotlib.

Incluye:
- Ejercicios de funciones y modelos matemáticos
- Actividades con gráficos y análisis de datos
- Resolución de problemas aplicados en contextos reales
- Prácticas y guías de trabajo en cuadernos de Jupyter

Este espacio sirve como portafolio académico y de aprendizaje para reforzar conceptos de matemática aplicada a través de la práctica.
